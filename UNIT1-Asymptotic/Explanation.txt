1. SHORT EXPLANATION OF ASYMPTOTIC NOTATION & THEORY
--------------------------------------------------------------------------------
Asymptotic analysis evaluates how the execution time or space requirements of 
an algorithm scale as the input size n approaches infinity. It ignores hardware-
specific constants and implementation quirks, focusing solely on the rate of 
growth.

Three primary asymptotic notations are used:

1. BIG-O NOTATION (O):
   - Definition: Asymptotic Upper Bound (Ceiling).
   - Inequality: f(n) <= c * g(n) for all n >= n0, where c > 0 and n0 >= 1.
   - Plain Meaning: The algorithm's growth rate will never exceed c * g(n) 
     for sufficiently large inputs. It characterizes the worst-case ceiling.
   - Example: Linear Search has worst-case time complexity O(n).

2. BIG-OMEGA NOTATION (Ω):
   - Definition: Asymptotic Lower Bound (Floor).
   - Inequality: f(n) >= c * g(n) for all n >= n0, where c > 0 and n0 >= 1.
   - Plain Meaning: The algorithm will take at least c * g(n) steps in the 
     growth limit. It characterizes the best-case floor.
   - Example: Linear Search has best-case time complexity Ω(1).

3. BIG-THETA NOTATION (Θ):
   - Definition: Asymptotically Tight Bound (Exact Growth Rate).
   - Inequality: c1 * g(n) <= f(n) <= c2 * g(n) for all n >= n0, where 
     c1, c2 > 0 and n0 >= 1.
   - Equivalence Theorem: A function f(n) is Θ(g(n)) if and only if f(n) is 
     both O(g(n)) AND Ω(g(n)).
   - Example: Merge Sort runs in Θ(n log n) across best, average, and worst cases.

Concrete Function Analysis: f(n) = 3n^2 + 2n + 1
- For large n, the highest-order term (n^2) completely dominates the linear 
  and constant terms (2n + 1).
- For n >= 1:
    3n^2 <= 3n^2 + 2n + 1 <= 3n^2 + 2n^2 + 1n^2 = 6n^2
- Setting c1 = 3, c2 = 6, and n0 = 1 proves that 3n^2 + 2n + 1 is Θ(n^2).

- Three Notation Cards (Color-Coded):

  - Green Card (Big-Omega): Highlights lower bound floor, inequality, and linear search Ω(1).
  - Purple Card (Big-Theta): Highlights tight bound sandwich, inequality, and merge sort Θ(n log n).

- Relationship Banner:
  Explicitly illustrates the fundamental equivalence theorem:
  f(n) is Θ(g(n)) <==> f(n) is O(g(n)) and f(n) is Ω(g(n)).

- Semi-Logarithmic Growth Rate Graph (n = 1 to 10):
  Plots representative values for four fundamental complexity classes:
    1. n (Linear - Blue): Grows gently from 1 to 10.
    2. n log2(n) (Linearithmic - Green): Grows moderately from 0 to ~33.22.
    3. n^2 (Quadratic - Purple): Grows faster from 1 to 100.
    4. 2^n (Exponential - Red): Explodes from 2 to 1024.

- Why a Logarithmic Vertical Axis (y = log10(value)) is used:
  Because 2^10 = 1024 is more than 100 times larger than n = 10, a standard 
  linear scale would compress the linear and linearithmic curves flat against 
  the x-axis. A logarithmic scale evenly distributes the decades (1, 10, 100, 
  1000, 10000), making every curve distinct, readable, and comparable.


3. KEY LAB VIVA POINTS
--------------------------------------------------------------------------------
Q: What is the main difference between Big-O and Big-Theta?
A: Big-O only provides an upper bound (the algorithm runs no slower than this), 
   which may or may not be tight. Big-Theta provides a tight bound, meaning the 
   algorithm's running time grows at exactly that rate from both above and below.

Q: If an algorithm is O(n^2), is it also O(n^3)?
A: Yes, because Big-O is an upper bound ceiling. Any function bounded above 
   by n^2 is automatically bounded above by n^3. However, it is NOT Θ(n^3).

Q: Why do we ignore constant factors in asymptotic analysis?
A: Constant multipliers depend on hardware speed, compiler optimizations, 
   and programming language overhead. Asymptotic analysis focuses on how 
   the algorithm scales with problem size n, independent of machine specifics.

Q: Why is Linear Search Ω(1) but O(n)?
A: In the best case, the target element is at index 0 (1 comparison, Ω(1)). 
   In the worst case, the target is at the end or not present (n comparisons, O(n)).

Q: State the condition under which f(n) = Θ(g(n)).
A: f(n) is Θ(g(n)) if and only if there exist positive constants c1, c2, and n0 
   such that c1 * g(n) <= f(n) <= c2 * g(n) for all n >= n0. Equivalently, 
   f(n) must be both O(g(n)) and Ω(g(n)).
